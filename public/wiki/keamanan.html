Keamanan Sistem Informasi & Keamanan Siber

Modul informasi publik fitur keamanan bdPay (PT Berkah Digital Pembayaran). Selaras praktik ISO 27001:2022.

Keamanan Sistem Informasi (SI)

Akses Role terpisah: Pengguna, Merchant, Admin. Sesi berbatas waktu (idle ~3 menit + countdown).
Kredensial Password di-hash, PIN transaksi 6 digit, captcha login (kecuali Google OAuth), OTP email/SMS/WA (konfigurasi).
Data Penyimpanan JSON terenkripsi AES untuk file sensitif; media KYC dengan watermark audit; minimasi data pada API publik.
Audit Log aktivitas admin/merchant, laporan risiko, jejak webhook & callback pembayaran.
Ketersediaan Mode maintenance: hanya Admin; pengguna & merchant logout paksa.

Keamanan Siber

Perimeter Whitelist/Blacklist IP & domain; pemblokiran akses tidak sah.
Fraud ML Deteksi pola anomali (frekuensi transaksi kecil, rekening berulang, perangkat/lokasi baru) → peringatan / On-Hold.
KYC Anti-fraud OCR KTP dengan cek blur/pantulan/metadata; liveness kamera; dokumen menengah tersimpan untuk review.
2FA Admin Google Authenticator (TOTP) setelah login admin pertama / setelah cleanup demo.
Channel Webhook omnichannel bertanda tangan; monitoring saluran API sandbox/production.
Transaksi Verifikasi callback VA/QRIS multi-gateway; limit per pengguna & kategori merchant.

Tanggung jawab pengguna

  • Jangan bagikan OTP, PIN, atau password.
  • Gunakan perangkat dan jaringan tepercaya.
  • Laporkan anomali lewat Kotak Pesan / kontak resmi.

Informasi ini bersifat edukasi produk. Kebijakan formal ada di S&K / Agreement portal.
